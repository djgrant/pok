# @pokjs/create

Project scaffolding CLI for pok.

## Usage

```bash
bun create @pokjs/create my-project
cd my-project
bun install
bun pok
```

## What's Created

```
my-project/
├── commands/
│   ├── hello.ts
│   └── build.ts
├── pok
├── package.json
├── tsconfig.json
└── .gitignore
```
