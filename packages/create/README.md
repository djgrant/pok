# create-pokit

Project scaffolding CLI for pok.

## Usage

```bash
bun create pokit my-project
# or
npx create-pokit my-project

cd my-project
pok
```

## What's Created

```
my-project/
├── commands/
│   ├── hello.ts
│   └── build.ts
├── pok
├── package.json
├── tsconfig.json
└── .gitignore
```
