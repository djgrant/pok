# Completing a Work Package

1. **Read** the work package to understand the task
2. **Move** from `todo/` to `in-progress/`
3. **Do the work** within scope defined in the package
4. **Write Output** - Fill the Output section with findings/results
5. **Verify** if appropriate (type check, test, etc.)
6. **Move** to `completed/`

## Stay in Scope

Only modify what's defined in the package. If you find additional issues, either:
- Note them in the Output section, OR
- Create new work packages in `todo/` if instructed to do so
